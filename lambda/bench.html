Управление

Открывать через HTTP-сервер из папки dist/: python -m http.server 8000 --directory dist → http://localhost:8000/bench.html; node build.mjs кладёт bench.html и bench.js в dist/ сам. Каждый вариант грузится в скрытом iframe с cache-buster; не переключайте вкладку во время замера (requestAnimationFrame в фоне не вызывается). localStorage less.js чистится самой страницей.
