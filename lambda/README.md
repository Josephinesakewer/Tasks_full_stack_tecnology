# Lambda — вёрстка макета `18.psd`

Готовый адаптивный лендинг ресторана греческой кухни, свёрстанный по PSD-макету
`C:\Users\Professional\Downloads\04\18.psd` (холст 1600 × 5000 px).

**Стек:** HTML5 + **Flexbox** + **Less** (компилируется в CSS) + минимальный vanilla JS.

---

## Быстрый старт

```bash
# 1. зависимости (компилятор Less)
pnpm install          # либо: npm install

# 2. сборка CSS из Less
npm run build         # минифицированный css/style.css
npm run build:dev     # читаемый css/style.css
npm run watch         # пересборка при изменении
```

Открыть `index.html` в браузере (сборка и сервер не требуются — это статический сайт).

> Если `lessc` не установлен глобально, можно собрать напрямую:
> `pnpm exec lessc less/style.less css/style.css`

поэтому масштабируется без потерь и не требует отдельного файла.

## Адаптивность

Вёрстка mobile-last: базовые стили — десктопные, переопределения — в миксинах
`.on-xl()` / `.on-lg()` / `.on-md()` / `.on-sm()`.

| Брейкпоинт | Перестройка |
|---|---|
| **≤ 1200 px** | уменьшаются кегли, фото и отступы; сетка сохраняется |
| **≤ 992 px** | навигация уезжает в боковое меню под бургер; hero и блоки ниже; меню остаётся в 2 колонки |
| **≤ 768 px** | все секции в одну колонку: фото → текст, галерея над формой, подвал в столбик, паттерн мельче |
| **≤ 576 px** | форма в одну колонку, кнопки на всю ширину, минимальные кегли |

Проверено в Chrome (headless, через DevTools Protocol) на ширинах
**1440 / 992 / 768 / 375 px** — скриншоты в `build/shots2/`.

## Flexbox

Flex используется для всех раскладок, в том числе:

* `.flex-row()`, `.flex-col()`, `.flex-center()`, `.flex-between()`, `.flex-wrap()` — миксины в `mixins.less`;
* шапка: `logo | nav (margin-left:auto) | social | burger`;
* hero и плашки — центрирование по обеим осям;
* about: текст + фото в ряд, на планшете `flex-direction: column` + `order`;
* меню: 2 колонки, внутри — вертикальные стеки блюд, строка «название … цена» через `justify-content: space-between` и `flex-wrap`;
* форма: строки полей `flex` + `space-between`, на мобильном `flex-direction: column`;
* подвал: 3 равные колонки, на мобильном — столбик.

## Доступность и мелочи

* семантические теги (`header`, `main`, `section`, `footer`, `blockquote`, `form`, `label`);
* скрытые подписи и `aria-label` для иконочных ссылок и бургера;
* фокус полей подсвечивается золотым, `scroll-margin-top` учитывает фиксированную шапку;
* JS не обязателен для просмотра — только мобильное меню и подсветка активного пункта.
